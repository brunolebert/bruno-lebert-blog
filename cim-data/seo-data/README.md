# CIM Data — Exports éditoriaux

Ces fichiers sont destinés au CHAT ÉDITORIAL BLOG ACTIF.

## Points d'entrée
- `index.json` : couverture, statistiques globales, statuts.
- `territoires/{code_INSEE}.json` : statistiques et voies.
- `cas-temoins.json` : exemples territoriaux réels.

## Méthode
- Transactions signées DVF, pas prix d'annonces.
- Prix médian et quartiles descriptifs uniquement si au moins
  cinq comparables répondent aux critères.
- Une voie n'est pas automatiquement un quartier.
- Les chiffres ne sont pas une estimation individuelle.
- Une adresse présente dans BAN ne justifie pas une page SEO.
- L'éditorial décide des pages pertinentes et de leurs titres.
- Données de bâtiments, DPE, copropriétés et réseaux non
  certifiées dans ce premier export.
- Les statistiques issues d'un petit effectif doivent être
  présentées avec leurs limites ; pas de scores inventés.
